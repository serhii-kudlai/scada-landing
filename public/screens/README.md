# Скриншоты для раздела "Примеры проектов"

## Правило именования файлов

Каждый скриншот идёт в **двух вариантах** (для светлой и тёмной темы):

```
{id}-light.png   — показывается при светлой теме (html без класса .dark)
{id}-dark.png    — показывается при тёмной теме  (html с классом .dark)
```

## Текущие слоты (id ↔ описание)

| id         | Описание карточки                     |
|------------|---------------------------------------|
| `dashboard`| Главный дашборд мониторинга           |
| `mnemonic` | Мнемосхема технологического процесса  |
| `alarms`   | Система аварий и событий              |
| `trends`   | Тренды и архивы данных                |
| `plc`      | Управление ПЛК / контроллерами        |
| `ai-chat`  | AI-ассистент оператора                |

## Пример

```
public/screens/
├── dashboard-light.png
├── dashboard-dark.png
├── mnemonic-light.png
├── mnemonic-dark.png
├── alarms-light.png
├── alarms-dark.png
├── trends-light.png
├── trends-dark.png
├── plc-light.png
├── plc-dark.png
├── ai-chat-light.png
└── ai-chat-dark.png
```

## Рекомендуемые параметры

- Формат: PNG (или WebP)
- Размер: **1600 × 1000 px** (соотношение 16:10)
- Сжатие: TinyPNG или аналог

Если файл отсутствует — на его месте отображается плейсхолдер с указанием ожидаемого имени файла.
