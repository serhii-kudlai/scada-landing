# Скриншоты интерфейса для лендинга

Используются в Hero (`shema`) и в разделе «Интерфейс» (`src/components/ProjectScreens.astro`).

## Именование

```
{id}_{lang}_light.png   — светлая тема (html без .dark)
{id}_{lang}_dark.png    — тёмная тема  (html.dark)
```

`{lang}`: `en`, `ru`, `ua` (для локали `uk`), `de`, `es`, `fr`, `ar`, `zh`.

## Слоты

| id          | Экран OBJECTSCADA                         | Маршрут в приложении        |
|-------------|-------------------------------------------|-----------------------------|
| `dashboard` | Панель мониторинга                        | `/`                         |
| `shema`     | Просмотр мнемосхемы (также Hero)          | `/schemas/view/:id`         |
| `editor`    | Редактор мнемосхем в режиме правки        | `/schemas/builder/:id`      |
| `alarms`    | Аварии и события                          | `/alarms`                   |
| `trends`    | Тренды (4 датчика, 6 ч, настройки свёрнуты)| `/trends`                   |
| `devices`   | Список устройств                          | `/devices`                  |
| `logs`      | Журнал действий пользователей             | `/user-activity-logs`       |

Список слотов задаётся в `src/i18n/*.json` → `screens.items`.

## Как снимались (v5.0.5)

- Проект «Pasteurizer» (ПЛК Nocado), тема приложения `gray`. Съёмка — Playwright
  из `scada/tools/screenshots` (браузер и кэш сессии `.auth/state.json`).
- Для съёмки в БД добавлены демо-данные:
  - 10 аварий (4 новых, 3 квитированных, 3 закрытых), `Accident.data.landing_demo = true`;
  - 16 записей журнала действий, `UserActivityLog.metadata.landing_demo = true`;
  - 6-часовая история TT01–TT04 (профиль партии: нагрев → выдержка → охлаждение),
    точки на границах 15 с без микросекунд.
- Мнемосхема и редактор сняты после «Fit to screen» со свёрнутой лентой миниатюр;
  редактор открыт кнопкой «Edit» из просмотра (прямой `/schemas/builder/:id`
  перенаправляет в просмотр до загрузки `can_edit`).
- Тренды: пресет 6H, TT01–TT04, «Show Chart», блок настроек свёрнут.
- Окно 1600 × 1000 px, PNG.
- Язык и тема задаются через `localStorage` (`language`, `darkMode`, `persist:root.settings`) перед загрузкой страницы.
