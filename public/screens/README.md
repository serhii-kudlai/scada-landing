# Скриншоты для раздела "Примеры проектов"

## Правило именования файлов

Каждый скриншот идёт в **двух вариантах** (для светлой и тёмной темы) и для **каждого языка**:

```
{id}_{lang}_light.png   — показывается при светлой теме (html без класса .dark)
{id}_{lang}_dark.png    — показывается при тёмной теме  (html с классом .dark)
```

Где `{lang}` — код языка страницы: `en`, `ru`, `de`, `uk`, `es`, `fr`.

## Текущие слоты (id ↔ описание)

| id          | Описание карточки                     |
|-------------|---------------------------------------|
| `dashboard` | Главный дашборд мониторинга           |
| `shema`     | Мнемосхема технологического процесса  |
| `alarms`    | Система аварий и событий              |
| `trends`    | Тренды и архивы данных                |
| `connections` | Подключения к полевому оборудованию и серверам |
| `logs`      | Журналы и история событий             |

## Рекомендуемые параметры

- Формат: PNG (или WebP)
- Размер: **1600 × 1000 px** (соотношение 16:10)
- Сжатие: TinyPNG или аналог

Если файл отсутствует — на его месте отображается плейсхолдер.
